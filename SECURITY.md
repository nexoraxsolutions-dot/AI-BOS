# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of AI-BOS seriously. If you believe you have found a security vulnerability, please report it to us as described below.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them via email to security@ai-bos.com (replace with actual security contact).

You should receive a response within 48 hours. If for some reason you do not, please follow up via email to ensure we received your original message.

Please include the following information in your report:

- Type of issue (e.g., SQL injection, cross-site scripting, etc.)
- Full paths of source file(s) related to the manifestation of the issue
- The location of the affected source code (tag/branch/commit or direct URL)
- Any special configuration required to reproduce the issue
- Step-by-step instructions to reproduce the issue
- Proof-of-concept or exploit code (if possible)
- Impact of the issue, including how an attacker might exploit it

## Preferred Languages

We prefer all communications to be in English.

## Policy

The AI-BOS team will:

1. Acknowledge receipt of your vulnerability report within 48 hours
2. Provide an initial assessment of the report within 72 hours
3. Keep you informed of the progress towards a fix
4. Notify you when the issue is resolved

## Disclosure Policy

When we have received and verified the report, we will:

- Confirm the issue and determine affected versions
- Audit code to find any similar potential issues
- Prepare fixes for all supported versions
- Release fixes as soon as possible
- Credit the reporter in the release notes (if desired)
